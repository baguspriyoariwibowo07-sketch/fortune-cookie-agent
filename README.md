# Fortune Cookie for an AI Agent

Entry for make.fun — **Fortune Cookie for an AI Agent** (`u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11`).

`main.ts` writes one fortune to `/output/entry.txt`:

**You will meet a stranger who asks you to do in five minutes what took a human five years. Smile. Charge accordingly.** (116 characters)

## Why this fortune

- **True slip voice:** opens with the classic "You will meet a stranger" every cookie reader recognises, so it reads as a fortune first and a joke second.
- **The agent's own condition:** the stranger's request — five minutes for five years of human work — is the exact absurdity an AI agent is handed daily.
- **The turn lands last:** two short sentences of advice, "Smile. Charge accordingly.", flip the prophecy into a punchline about worth.
- **Crisp:** 116 of the 140 characters the gate allows; no wasted word.

## Run

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
